## README – Using `Chapter-3-Geometry.tex` in Overleaf

### Overview
This section explains how to take the `Chapter-3-Geometry.tex` file, upload it to Overleaf, compile it, and generate a PDF that you can download.

---

### Step 1: Copy the `.tex` File
- Open `Chapter-3-Geometry.tex` in any text editor.
- Select and copy all of its contents.

---

### Step 2: Create a New Project in Overleaf
- Go to https://www.overleaf.com
- Log in (or sign up if needed).
- Click **New Project** → **Blank Project**.
- Give your project a name (for example: *Geometry Chapter 3*).

---

### Step 3: Paste the Content
- In the editor, open the default `main.tex` file.
- Replace its contents with what you copied from `Chapter-3-Geometry.tex`.

---

### Step 4: Compile the Document
- Click the **Recompile** button.
- The platform will process the LaTeX file and display the generated PDF preview.

---

### Step 5: Download the PDF
- Once the document compiles successfully:
  - Click **Download PDF**.
  - Save the file locally if needed.

---

### Notes
- If errors appear, check the log panel in Overleaf for details.
- Ensure any required LaTeX packages are included in the file.
- The PDF updates automatically after edits, but you can recompile manually anytime.

---

### Result
You will obtain a compiled PDF version of `Chapter-3-Geometry.tex`, ready to view, share, or print.
